API Dans le coin

Récupérez les sorties et les lieux à visiter de « Dans le coin » dans votre site, votre application ou votre borne, avec votre propre clé.

Mise à jour : 13 octobre 2026

Obtenir une clé

Chaque clé est personnelle et réglée pour son usage : départements, types de sorties, nombre d’appels par jour et sites autorisés. Pour en demander une, écrivez à clementer@gmail.com en indiquant votre structure, votre site et les départements voulus.

Adresse

https://dans-le-coin.<compte>.workers.dev

La clé se transmet dans l’en-tête X-API-Key (recommandé) ou dans le paramètre cle.

Sorties

GET /v1/sorties

ParamètreExempleRôle
dep03,58Départements (6 au plus). Facultatif si votre clé est réglée sur des départements.
typebrocante,fetebrocante, fete, spectacle, culture, famille, sport
du / au2026-10-14Période (par défaut : à partir d’aujourd’hui)
communeMoulinsUne seule commune
qmarchéMot recherché dans le titre, le lieu et la description
gratuit1Seulement les sorties gratuites
limite / page100 / 1Pagination (500 au plus par page)

Chaque sortie : id, titre, type, debut, fin, heure, autres_dates, commune, departement, lieu, description, lien, image, gratuit, latitude, longitude, source.

Lieux à visiter et offices de tourisme

GET /v1/lieux — mêmes paramètres dep, commune, q, limite, page ; type parmi office, musee, patrimoine, nature, loisirs.

Chaque lieu : id, nom, type, commune, departement, adresse, description, site, telephone, horaires_osm (format OpenStreetMap), label, principal, latitude, longitude, source.

Départements

GET /v1/departements — liste des départements accessibles avec votre clé et leur nombre de sorties.

Exemple

fetch("https://dans-le-coin.<compte>.workers.dev/v1/sorties?dep=03&type=brocante&limite=20", {
  headers: { "X-API-Key": "dlc_votre_cle" }
}).then(r => r.json()).then(d => console.log(d.total, d.resultats));

Erreurs

  • 401 cle_invalide : clé absente ou inconnue ; 403 cle_revoquee ; 403 origine_refusee : site non autorisé pour cette clé.
  • 403 departement_non_autorise ; 403 type_non_autorise ; 400 dep_requis ; 429 quota_atteint : nombre d’appels du jour dépassé (en-tête X-Quota-Restant).

Conditions

  • Données mises à jour chaque nuit ; réponses mises en cache 10 minutes.
  • Affichez « Dans le coin » et la source de chaque fiche. Les données restent sous la licence de leurs producteurs (voir les mentions légales) ; les horaires viennent d’OpenStreetMap (ODbL).
  • Une clé peut être suspendue en cas d’usage abusif.
