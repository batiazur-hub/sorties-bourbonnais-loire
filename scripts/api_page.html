Démarrage rapide

  1. Obtenez une clé. Elle commence par dlc_ et est réglée pour votre usage : sites autorisés, zone, types d’événements.
  2. Ajoutez le script avec votre clé dans l’adresse, comme pour Google Maps.
  3. Appelez l’API dans la fonction de rappel, ou posez directement un widget.
<div id="agenda"></div>

Clés et restrictions

Chaque appel exige une clé. Comme une clé Google Maps, une clé utilisée dans une page web est visible par les visiteurs : c’est la restriction par site qui la protège. Chaque clé est réglée à sa création :

RestrictionEffetExemple
Sites autorisésLa clé ne répond qu’aux pages de ces adresses. Indispensable pour une clé utilisée dans un navigateur.https://www.ville-moulins.fr
ZoneSeuls les événements et lieux situés dans le cercle sont renvoyés.25 km autour de Moulins
DépartementsListe des départements accessibles.03, 58, 71
TypesCatégories d’événements ou de lieux accessibles.brocante, musee
PériodeNombre de jours à venir au plus.30 jours
QuotaNombre d’appels par jour (5 000 par défaut).5 000
Depuis un serveur (PHP, Python, application mobile) : ne publiez pas la clé, passez-la dans l’en-tête X-API-Key et gardez-la dans une variable d’environnement.

Pour vérifier les réglages d’une clé : TrucsAFaire.cle() ou GET /v1/cle.

Gérer les erreurs

try {
  const r = await TrucsAFaire.sorties({ commune: "Nevers", dep: "58" });
} catch (e) {
  if (e instanceof TrucsAFaire.Erreur) {
    console.warn(e.code, e.statut, e.message);  // ex. "quota_atteint", 429
  }
}

API REST

Pour un serveur, une application mobile ou une borne : des requêtes GET qui renvoient du JSON.

GEThttps://VOTRE-SERVEUR/v1/sortiesGEThttps://VOTRE-SERVEUR/v1/lieuxGEThttps://VOTRE-SERVEUR/v1/departementsGEThttps://VOTRE-SERVEUR/v1/cle

Clé dans l’en-tête X-API-Key (recommandé côté serveur) ou dans le paramètre key.

curl -H "X-API-Key: VOTRE_CLE" \
  "https://VOTRE-SERVEUR/v1/sorties?lat=46.566&lon=3.333&rayon=25&type=brocante&tri=distance"
const url = new URL("https://VOTRE-SERVEUR/v1/sorties");
url.search = new URLSearchParams({ dep: "03", type: "brocante,fete", limite: 20 });

const r = await fetch(url, { headers: { "X-API-Key": process.env.DLC_CLE } });
const { total, resultats } = await r.json();

Erreurs et quotas

StatutCodeSignification
400dep_requisNi département, ni position, ni zone réglée sur la clé.
400trop_de_departementsPlus de 8 départements en un appel.
401cle_invalideClé absente ou inconnue.
403cle_revoqueeClé désactivée.
403origine_refuseePage appelante non autorisée pour cette clé.
403departement_non_autorise, type_non_autoriseHors des réglages de la clé ; la réponse liste ce qui est autorisé.
429quota_atteintQuota du jour atteint ; il se renouvelle à minuit (UTC).

Chaque réponse porte l’en-tête X-Quota-Restant. Les réponses sont mises en cache 10 minutes : inutile d’appeler plus souvent.

Essayer l’API

Composez une requête et lancez-la. Sans clé, la console interroge les données publiques en mode démonstration, avec le même format de réponse.

Conditions

  • Données mises à jour chaque nuit ; les horaires des lieux viennent d’OpenStreetMap (ODbL).
  • Affichez « Trucs à faire » et la source de chaque fiche (les widgets le font pour vous). Les données restent sous la licence de leurs producteurs : voir les mentions légales.
  • Une clé peut être suspendue en cas d’usage abusif ou de revente des données.
  • Questions, demande de clé ou de quota plus élevé : clementer@gmail.com.
